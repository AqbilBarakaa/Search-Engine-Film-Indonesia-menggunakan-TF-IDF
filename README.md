# Search-Engine-Film-Indonesia-menggunakan-TF-IDF
Aplikasi Search Engine Film Indonesia menggunakan TF-IDF

## Menggunakan Dataset IMDb Indonesian Movies
[IMDb Indonesian Movies](https://www.kaggle.com/datasets/dionisiusdh/imdb-indonesian-movies)

## Clone Repo
   ```bash
   # clone repo dengan git command berikut
   $ git clone https://github.com/AqbilBarakaa/Search-Engine-Film-Indonesia-menggunakan-TF-IDF.git

   # masuk ke folder project
   $ cd Search-Engine-Film-Indonesia-menggunakan-TF-IDF

   # Buka di text editor
   $ code .
   ```

## Run Aplikasi
   ```bash
   # Run Aplikasi
   $ php artisan serve
   ```
